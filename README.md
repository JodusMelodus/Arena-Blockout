# Arena Blockout
Arena Blockout is a custom Minecraft datapack heavily inspired by the tactical FPS extraction shooter _Arena Breakout: Infinite._

**Note:** This project is currently in early development. Features and mechanics are actively being updated!

## Features
- **Pure Vanilla Integration:** Built purely as a datapack—no mods, external dependencies, or complex client setups required. Easily drag and drop into any existing world.
- **Tactical Extraction Gameplay:** Built to bring high-stakes gunplay, looting, and survival directly into Minecraft.

## Keybind Setup
To ensure the controls feel like a true tactical shooter, we **strongly recommend** adjusting your keybinds before playing:
| Action               | Keybind      |
| -------------------- | ------------ |
| Attack/Destroy       | Right Button |
| Use Item/Place Block | Left Button  |
| Drop Selected Item   | Z            |

## Project Vision
The long-term goal for Arena Blockout is to create 1:1 recreations of iconic Arena Breakout maps, custom loot zones, and a full extraction loop.

Whether you're looking to host intense tactical raids on a private server with friends or compete on a public high-stakes server, Arena Blockout is built from the ground up to support high-intensity PvPvE gameplay.
